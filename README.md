# Routing Subspaces: project page

Project page for *Routing Subspaces: Auditing Evaluation-to-Deployment Mismatch in Fine-Tuned Language Models* (Phongsakon Mark Konrad, Toygar Tanyel, Serkan Ayvaz; NeurIPS 2026, poster), served at https://aiml-sdu.github.io/routing-subspaces-page/.

This repository holds the built static page only: `index.html` and `static/`. The page's data files (`static/js/data.js`, `static/js/examples.js`) are generated from the paper's stored results; the code, data splits, results and generator scripts will be released at https://github.com/aiml-sdu/routing-subspaces.
